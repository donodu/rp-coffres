ÉTAPE 1 — SUPABASE
------------------
1. Ouvre ton projet Supabase.
2. Va dans SQL Editor > New query.
3. Ouvre 00_INSTALLATION_COMPLETE_SUPABASE.sql avec le Bloc-notes.
4. Fais Ctrl+A puis Ctrl+C.
5. Colle tout dans Supabase.
6. Clique sur Run.
7. Le résultat attendu est : Success. No rows returned.

5. Enregistre.

ÉTAPE 3 — GITHUB
----------------
1. Crée un dépôt public, par exemple rp-coffres.
2. Clique Add file > Upload files.
3. Glisse TOUS les fichiers de ce dossier, ainsi que le dossier assets.
4. Vérifie que index.html est directement à la racine du dépôt.
5. Clique Commit changes.
6. Settings > Pages.
7. Source : Deploy from a branch.
8. Branch : main ; dossier : /(root).
9. Clique Save et attends 1 à 3 minutes.
