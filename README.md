# Silver Phoenix Command Center

Site complet pour GitHub Pages, connecté à Supabase et Discord.

## Fonctions

- coffres communs avec images d’objets ;
- dépôts, retraits et ajustements sécurisés ;
- historique visible uniquement par les trois plus hauts grades ;
- section de coffres personnels visible uniquement par ces trois grades ;
- gestion des membres et des grades ;
- suppression définitive d’un objet uniquement par le Commandeur suprême ;
- tous les nouveaux comptes commencent en Recrue ;
- design noir, argent et violet, adapté au téléphone.

Commence par lire `GUIDE_REPARTIR_DE_ZERO.txt`.
